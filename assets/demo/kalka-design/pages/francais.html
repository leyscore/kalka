Votre agent pose la base. Vous peaufinez à la main.

Un agent IA vous sort une landing page en quelques secondes. Mais pour la retoucher, il faut encore mettre les mains dans le code. Dans Kalka, ce qu'écrit votre agent arrive sur le canevas en vrais calques : déplacez-les, restylez-les, gardez ce qui marche.
