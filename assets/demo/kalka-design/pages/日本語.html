下書きはエージェント、仕上げはあなたの手で。

AI エージェントなら、ランディングページは数秒で書き上がります。ただ、手直ししようとすると結局コードを掘り返すことに。Kalka では、エージェントが書いたものが本物のレイヤーとしてキャンバスに並びます。動かして、スタイルを変えて、いいところだけ残しましょう。

  3. 3
    あなたが目で見て仕上げる

レイヤーはすべて HTML 要素

レイヤーパネルは DOM そのもの。レイヤーを選べば対応するタグがすぐそこにあり、コードを書き換えればキャンバスも追従します。

Figma が使えれば、Kalka も使える

パネルもツールも、手になじんだ操作もそのまま。開いたらすぐデザインに取りかかれます。

シェーダーレイヤー

シェーダーがキャンバスで動く

メッシュグラデーション、グレイン、流れる光。ほかのレイヤーと同じ感覚で調整できます。

カンプから本番公開まで、関わるすべての人に。

デザイナー

描いたものが、そのまま本番に出ます。「カンプと見た目が違う」とはもう言われません。影も余白も文字組みも、デザインしたとおりです。

開発者

カンプを読み解いて組み直す必要はありません。届くのは本物の HTML と CSS。ほかのコードと同じように diff を見て、レビューして、マージできます。

制作会社とフリーランス

どの案件からも「組み直し」の工程がなくなります。「ここ、4px ずらしてもらえますか」の往復が減り、納品も早まります。

使い慣れたデザイン用語のまま、Web が動く CSS へ。

ただのファイル HTML、CSS、JSON が自分のフォルダに入るだけ。どのコードエディターでも開けます。
Git を標準搭載 コードレビューと同じ流れで、デザインもブランチを切り、diff を見て、レビューできます。
データは手元のマシンに デスクトップアプリなので、プロジェクトを PC の外に出す必要はありません。
