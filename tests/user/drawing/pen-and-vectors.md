# Pen and vectors

**Story:** as an illustrator, I want to draw and edit custom shapes, so that I can make icons and illustrations in place.

**Start:** `/?test`, an artboard.

## Missions

### Draw a path

Draw a closed shape with straight and curved segments.

- **In Figma:** P, click for corners, drag for curves, click the first point to close, Enter to finish.
- **In Kalka, watch for:** Same gestures; the path closes and fills.

### Edit points

Move a point and turn a corner into a curve.

- **In Figma:** Double-click the shape (or Enter) to edit; Cmd/Ctrl-drag or double-click a point toggles curve.
- **In Kalka, watch for:** An edit mode with the same gestures.

### Outline a stroke

Turn a thick line into a filled shape.

- **In Figma:** Outline stroke: Cmd+Alt+O on Mac, Ctrl+Alt+O on Windows.
- **In Kalka, watch for:** An equivalent command exists.
