# Icons

**Story:** as a UI designer, I want to add icons without leaving the editor, so that I do not need a plugin.

**Start:** `/?test`, a button with a label.

## Missions

### Insert an icon

Put an arrow icon before the button label.

- **In Figma:** Usually a plugin (Iconify) or a team icon library.
- **In Kalka, watch for:** The icon picker is easy to find and the icon lands in the button.

### Recolor and resize

Make the icon 20 px and the button text color.

- **In Figma:** Change the vector fill or stroke and scale with K.
- **In Kalka, watch for:** The color and size change without breaking the icon.

### Swap

Replace the arrow by another icon.

- **In Figma:** Instance swap if the icon is a component.
- **In Kalka, watch for:** Swapping keeps size and color.
