# Fills, strokes and effects

**Story:** as a visual designer, I want to style shapes with colors, gradients, borders and shadows, so that my mockups look finished.

**Start:** `/?test`, a card frame.

## Missions

### Gradient

Give the card a linear gradient and move its handles on the canvas.

- **In Figma:** The fill picker switches Solid to Linear; handles edit on the canvas.
- **In Kalka, watch for:** Same; the handles are on the canvas.

### Several fills

Stack a color and a semi-transparent image on the card.

- **In Figma:** The + in Fill adds layers of paint, top one on top.
- **In Kalka, watch for:** Several fills, in the same order.

### Border

Add a 1 px inside border, then a dashed one.

- **In Figma:** Stroke section: weight, position (Inside, Center, Outside), dashes in the stroke settings.
- **In Kalka, watch for:** The same settings, and the stroke draws where set.

### Shadow and blur

Add a drop shadow, then a background blur.

- **In Figma:** Effects section: Drop shadow, Inner shadow, Layer blur, Background blur.
- **In Kalka, watch for:** All four effects.

### Copy a style

Copy the card style to another frame.

- **In Figma:** Copy properties (Cmd+Alt+C) and Paste properties (Cmd+Alt+V).
- **In Kalka, watch for:** An equivalent exists.
