# Images

**Story:** as a designer laying out a page, I want to place, crop and swap images, so that I can work with real photos.

**Start:** `/?test`, an artboard and two image files on the desktop.

## Missions

### Place images

Drag the two image files onto the artboard.

- **In Figma:** Dropped images become rectangles with an image fill, at their size or scaled to fit.
- **In Kalka, watch for:** They land where dropped, inside the artboard.

### Crop

Crop one image to show only a face.

- **In Figma:** Double-click the image > Crop, or set the fill to Crop and drag.
- **In Kalka, watch for:** A crop mode reachable the same way.

### Fill a shape

Fill a circle with the other image, then switch between Fill, Fit and Tile.

- **In Figma:** The image fill modes in the fill picker.
- **In Kalka, watch for:** The same modes.

### Swap

Replace one image by another file, keeping size and crop.

- **In Figma:** Choose image in the fill picker.
- **In Kalka, watch for:** Replacing keeps the layer size.
