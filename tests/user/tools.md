# Tools

**Player:** a Figma user. **Start:** `/?test`, a new document with one artboard.

## Missions

### Switch between every tool

Pick each tool in the bottom toolbar in turn, then go back to Move. Do it again with the shortcuts: V, F, R, O, L, P, T, H.

Watch for: one click on any tool switches to it from any other, including from the comment tool; the active tool is always the one shown pressed; Escape returns to Move as in Figma.

### Comment, then keep designing

Turn on comments (C), place one, then without turning comments off pick the rectangle tool and draw.

Watch for: picking a tool leaves comment mode; the click on the canvas draws, it does not pin another comment.

### Use a tool once

Draw a rectangle, then click on the canvas again.

Watch for: as in Figma, a shape tool returns to Move after one shape; holding Shift or double-clicking the tool keeps it, if Kalka supports that.

### Pan and zoom

Pan with Space and with the trackpad, zoom with Cmd/Ctrl and the wheel, Shift+1 to fit, Shift+2 for the selection.

Watch for: the same shortcuts as Figma; no tool stays switched after Space is released.
