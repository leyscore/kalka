# Exporting assets

**Story:** as a designer handing assets over, I want to export icons and images in the right formats and sizes, so that developers get what they need.

**Start:** `/?test`, an icon, a photo and a card.

## Missions

### PNG at 2x

Export the photo as PNG at 1x and 2x.

- **In Figma:** Export section > + > 2x; Export button; Cmd/Ctrl+Shift+E exports all.
- **In Kalka, watch for:** Same section, same scales.

### SVG

Export the icon as SVG.

- **In Figma:** Format SVG.
- **In Kalka, watch for:** A clean SVG that opens in a browser.

### Several at once

Export the three layers in one go.

- **In Figma:** Cmd/Ctrl+Shift+E lists every export.
- **In Kalka, watch for:** An equivalent, ideally one zip.

### Copy as PNG

Paste the card into a chat app as an image.

- **In Figma:** Cmd/Ctrl+Shift+C copies as PNG.
- **In Kalka, watch for:** An equivalent exists.
