# Exporting HTML

**Story:** as a designer handing a page to a developer, I want to export a page as clean HTML that draws the same everywhere, so that a developer can start from it.

**Start:** `/?test`, a page with a title, buttons and text in Inter and one other font, with a phone breakpoint.

## Missions

### Export

Export the desktop artboard as one HTML file with images inside.

- **In Figma:** No native equivalent; Dev Mode shows CSS per layer, plugins export code.
- **In Kalka, watch for:** Easy to find; one file when asked.

### Open everywhere

Open it in Chrome, Firefox and Safari, ideally without the fonts installed.

- **In Figma:** No equivalent.
- **In Kalka, watch for:** Same fonts as on the canvas; nothing extra (stray shapes, outlines, duplicate text); a title.

### Narrow window

Make the window as narrow as a phone.

- **In Figma:** No equivalent.
- **In Kalka, watch for:** The phone breakpoint applies; what sticks out.

### Read the code

Read the HTML as a developer would.

- **In Figma:** No equivalent.
- **In Kalka, watch for:** Meaningful class names; real buttons and links; no editor data.
