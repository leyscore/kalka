# Inspecting code

**Story:** as a developer, I want to read sizes, colors and CSS of a layer, so that I can build it without guessing.

**Start:** `/?test`, a designed card, opened by someone who does not design.

## Missions

### Inspect

Read the card spacing, colors and font.

- **In Figma:** Dev Mode (Shift+D): CSS, spacing redlines, variables.
- **In Kalka, watch for:** The code panel shows the same, with variables named.

### Copy code

Copy the card as HTML/CSS or JSX.

- **In Figma:** Dev Mode code snippets; plugins.
- **In Kalka, watch for:** Copying gives code that renders the same.
