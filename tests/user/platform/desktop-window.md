# The desktop window

**Story:** as a designer using the desktop app, I want tabs and window controls that behave like other desktop apps, so that it feels native.

**Start:** the desktop app with three documents open.

## Missions

### Tabs

Open, reorder and close tabs; reopen the last closed one.

- **In Figma:** Figma desktop: tabs, Cmd/Ctrl+W closes, Cmd/Ctrl+Shift+T reopens.
- **In Kalka, watch for:** Same shortcuts.

### Window

Drag the window by its top bar, double-click it, use the window buttons.

- **In Figma:** The tab bar is the title bar.
- **In Kalka, watch for:** Dragging works on empty bar space; the buttons are not hidden by the app.

### Open a file

Double-click a Kalka file in Finder or Explorer.

- **In Figma:** Opens in a new tab.
- **In Kalka, watch for:** Same.
