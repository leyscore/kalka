# A large file

**Story:** as a designer on a big project, I want the editor to stay fast with hundreds of screens, so that I am never slowed down.

**Start:** a document with 200 artboards and many images.

## Missions

### Navigate

Zoom out to see everything, then zoom into one screen.

- **In Figma:** Figma stays fluid, with low-resolution tiles while zooming.
- **In Kalka, watch for:** No freeze; time the first full view.

### Edit

Move and edit layers in a dense screen.

- **In Figma:** Instant.
- **In Kalka, watch for:** No lag between the pointer and the layer.

### Layers panel

Scroll the layers panel to the bottom.

- **In Figma:** Instant.
- **In Kalka, watch for:** The panel scrolls smoothly.
