# Keyboard and accessibility

**Story:** as a designer who works with the keyboard, I want to reach every panel and action without the mouse, so that I work fast and the app is accessible.

**Start:** `/?test`, a page with layers.

## Missions

### Shortcuts list

Find the list of shortcuts.

- **In Figma:** Ctrl+Shift+? opens the shortcuts panel; Cmd/Ctrl+/ opens quick actions.
- **In Kalka, watch for:** Equivalents exist.

### Quick actions

Run "Create component" by typing its name.

- **In Figma:** Cmd/Ctrl+/ then type.
- **In Kalka, watch for:** A command palette exists.

### Focus

Tab through the right panel fields and change a value.

- **In Figma:** Fields are reachable and Enter commits.
- **In Kalka, watch for:** Focus is visible everywhere.
