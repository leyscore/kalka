# Light and dark interface

**Story:** as a designer on macOS, Windows or Linux, in the desktop app or a browser, I want the interface to switch between light and dark smoothly, so that it is comfortable day and night.

**Start:** the dashboard, then a document.

## Missions

### Switch

Switch light and dark from the menu and from settings, on the dashboard and in a document.

- **In Figma:** Figma switches its UI theme instantly.
- **In Kalka, watch for:** On the dashboard the night sweeps down without any flash of white or black or blink of the window, and the window buttons follow; record the screen, a flash lasts a frame or two.

### Follow the system

Set System, then change the operating system appearance.

- **In Figma:** Figma follows the system.
- **In Kalka, watch for:** Kalka follows without a restart.
