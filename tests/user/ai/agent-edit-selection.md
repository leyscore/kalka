# Asking the agent about a selection

**Story:** as a designer polishing a screen, I want to ask the agent to change only what I selected, so that it does not touch the rest.

**Start:** a finished screen, one card selected.

## Missions

### Edit the selection

Ask to "make this card more compact".

- **In Figma:** Figma AI actions work on the selection (rename layers, rewrite text).
- **In Kalka, watch for:** Only the card changes.

### Rename layers

Ask to rename every layer sensibly.

- **In Figma:** Figma: Rename layers with AI.
- **In Kalka, watch for:** Names become meaningful.
