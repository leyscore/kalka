# Building with the agent

**Story:** as a designer using Kalka's agent, I want to ask for a page in words and get editable layers, so that I start from a draft instead of a blank artboard.

**Start:** `/` with a model configured, a new document.

## Missions

### Ask

Ask for "a landing page for a coffee subscription".

- **In Figma:** Figma Make and First Draft generate designs or code.
- **In Kalka, watch for:** The result is layers with auto layout and text styles, not a picture.

### Change

Ask to make the hero darker and the buttons rounder.

- **In Figma:** Figma Make edits code.
- **In Kalka, watch for:** Only those layers change; undo takes the change back.

### Keep going by hand

Edit the result by hand.

- **In Figma:** Figma itself.
- **In Kalka, watch for:** It edits like anything drawn by hand.
