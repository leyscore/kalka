# Comments

**Player:** a reviewer. **Start:** `/?test`, a page with a few sections.

## Missions

### Leave feedback

Pin three comments on different layers and reply to one.

Watch for: C or the toolbar button; the pin stays on its layer when the layer moves.

### Get back to work

Leave comment mode and select a layer on the canvas.

Watch for: Escape, C again, or picking any tool all leave comment mode; no stray comment is pinned on the way out.
