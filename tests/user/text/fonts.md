# Fonts

**Story:** as a brand designer, I want to use the brand font and any Google font, so that my designs use the right type.

**Start:** `/?test`, a text layer.

## Missions

### Google font

Set the text in a Google font that is not installed.

- **In Figma:** Figma lists Google fonts and loads them.
- **In Kalka, watch for:** The font is found by name and the text does not jump more than once.

### Local font

Use a font installed on this computer.

- **In Figma:** Figma needs its font installer for local fonts.
- **In Kalka, watch for:** Local fonts are listed (desktop app) or the limit is explained (browser).

### Missing font

Open a document whose font is missing.

- **In Figma:** A missing-font warning and Replace fonts.
- **In Kalka, watch for:** A clear warning and a way to replace it.
