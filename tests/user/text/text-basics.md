# Writing text

**Story:** as a Figma user, I want to add and edit text quickly, so that I can write real copy in my mockups.

**Start:** `/?test`, an artboard.

## Missions

### Headline

Add a headline, 48 px, bold.

- **In Figma:** T then click; Escape leaves editing with the text selected.
- **In Kalka, watch for:** Same; Escape keeps the layer selected.

### Paragraph in a box

Add a paragraph that wraps at 480 px wide.

- **In Figma:** T then drag a box; Fixed width with Auto height in the text resizing options.
- **In Kalka, watch for:** The same resizing choices: auto width, auto height, fixed.

### Part of a text

Make one word a different color and italic.

- **In Figma:** Select the word inside the text and change it.
- **In Kalka, watch for:** Only that word changes.

### Find and replace

Replace "Sign up" by "Get started" everywhere.

- **In Figma:** Cmd/Ctrl+F, Replace.
- **In Kalka, watch for:** An equivalent exists.
