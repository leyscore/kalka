# Typography details

**Story:** as a typographer, I want fine control over type, so that text looks right in every language.

**Start:** `/?test`, a few text layers.

## Missions

### Spacing

Set line height 140 %, letter spacing -2 %, paragraph spacing 12.

- **In Figma:** Typography section and its details panel.
- **In Kalka, watch for:** Same fields with the same units.

### Case and decoration

Make a label uppercase and a link underlined.

- **In Figma:** Type details: Case, Decoration.
- **In Kalka, watch for:** Same.

### Lists

Make a bulleted list and a numbered list.

- **In Figma:** List buttons in type details.
- **In Kalka, watch for:** Lists exist.

### Other scripts

Type Cyrillic, Arabic and Japanese lines.

- **In Figma:** Arabic runs right to left; fallback fonts fill missing glyphs.
- **In Kalka, watch for:** No missing-glyph boxes; right to left for Arabic.
