# Text styles

**Story:** as a design-system designer, I want to reuse named text styles, so that every heading looks the same.

**Start:** `/?test`, a page with headings.

## Missions

### Create a style

Save a heading as "Heading/H1".

- **In Figma:** Style icon in Typography > +.
- **In Kalka, watch for:** An equivalent, with grouping by slash.

### Apply

Apply H1 to two other headings.

- **In Figma:** Pick it from the style list.
- **In Kalka, watch for:** Same.

### Change everywhere

Make H1 bigger once and see every heading update.

- **In Figma:** Edit the style.
- **In Kalka, watch for:** All headings update.
