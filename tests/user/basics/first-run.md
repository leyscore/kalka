# First run

**Story:** as a designer who has used Figma for years, I want to get from opening Kalka to an empty page I can design on, so that I can judge the tool in the first minute.

**Start:** a fresh browser profile at `/` (not `/?test`), or the desktop app with a new profile.

## Missions

### Reach an empty canvas

Start from the welcome screen and reach a new, empty document.

- **In Figma:** Figma opens a new design file from the file browser in one click; nothing to set up first.
- **In Kalka, watch for:** Every screen says what to do next; nothing asks for an account or a key before you can draw; skipping the setup is obvious.

### Make a desktop page

Create an artboard the size of a desktop screen and name it "Home".

- **In Figma:** Press F, pick Desktop (1440 × 1024) in the right panel, double-click the name to rename it.
- **In Kalka, watch for:** The presets are where a Figma user looks; a 1440 preset exists; the tool returns to Move after the preset is picked.

### Leave and come back

Go to the dashboard, then back to the document.

- **In Figma:** The file browser and the file are tabs; nothing is lost.
- **In Kalka, watch for:** The document is unchanged and nothing asks to be saved when nothing changed.
