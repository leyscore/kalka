# Pages

**Story:** as a designer organizing a project, I want to split a file into pages, so that the file stays tidy.

**Start:** `/?test`, a new document.

## Missions

### Add and rename pages

Add pages "Cover", "Design" and "Archive".

- **In Figma:** The + in the Pages panel adds a page; double-click renames.
- **In Kalka, watch for:** Same; the new page opens.

### Move a layer to another page

Send an artboard from "Design" to "Archive".

- **In Figma:** Right-click > Move to page.
- **In Kalka, watch for:** An equivalent exists in the context menu.

### Reorder pages

Put "Cover" first.

- **In Figma:** Drag the page in the list.
- **In Kalka, watch for:** Drag works and the order is kept after reopening.
