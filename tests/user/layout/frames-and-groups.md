# Frames and groups

**Story:** as a Figma user, I want to wrap layers in a frame or a group, so that I can organize and move them together.

**Start:** `/?test`, three layers side by side.

## Missions

### Group

Group the three layers, then ungroup them.

- **In Figma:** Cmd/Ctrl+G groups, Cmd/Ctrl+Shift+G ungroups.
- **In Kalka, watch for:** Same shortcuts; the layers keep their place.

### Frame the selection

Wrap the three layers in a frame.

- **In Figma:** Cmd/Ctrl+Alt+G (Frame selection).
- **In Kalka, watch for:** An equivalent exists, and the frame fits the layers.

### Resize a frame only

Make the frame bigger without stretching what is inside.

- **In Figma:** Hold Cmd/Ctrl while resizing a frame to leave its children in place.
- **In Kalka, watch for:** An equivalent exists.
