# Grids and guides

**Story:** as a web designer, I want a column grid and guides to align to, so that my page follows a 12-column system.

**Start:** `/?test`, a 1440 artboard.

## Missions

### Column grid

Add a 12-column grid with 24 gutters and 80 margins.

- **In Figma:** Layout grid section > Columns; Ctrl+G toggles grids.
- **In Kalka, watch for:** A layout grid exists and layers snap to it.

### Guides

Drag a vertical guide from the ruler at x = 720.

- **In Figma:** Shift+R shows rulers; drag from a ruler to make a guide.
- **In Kalka, watch for:** Rulers and guides work the same way.

### Grid layout

Lay out six cards in a 3 × 2 grid that reflows.

- **In Figma:** Auto layout Grid (recent Figma).
- **In Kalka, watch for:** A grid layout option.
