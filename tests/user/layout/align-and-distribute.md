# Align and distribute

**Story:** as a Figma user, I want to align and space layers in one click, so that I do not nudge by hand.

**Start:** `/?test`, five scattered rectangles.

## Missions

### Align

Align them to the top, then center them in their artboard.

- **In Figma:** Align buttons at the top of the right panel; Alt+W/A/S/D/H/V shortcuts.
- **In Kalka, watch for:** The same buttons; one selected layer aligns to its parent.

### Distribute

Space them evenly horizontally.

- **In Figma:** Distribute horizontal spacing, or Tidy up (Ctrl+Alt+T).
- **In Kalka, watch for:** An equivalent exists.

### Match sizes

Give them all the same width.

- **In Figma:** Select all and type the width once.
- **In Kalka, watch for:** Typing once sets all; mixed values show as Mixed.
