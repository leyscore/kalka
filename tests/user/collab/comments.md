# Comments

**Story:** as a reviewer, I want to pin feedback on a design and answer it, so that the team discusses in place.

**Start:** `/?test`, a page with a few sections.

## Missions

### Comment

Pin three comments on different layers and reply to one.

- **In Figma:** C, click, type; threads in the comments panel.
- **In Kalka, watch for:** Same; a pin follows its layer when the layer moves.

### Back to work

Leave comment mode and select a layer.

- **In Figma:** Escape, or pick a tool.
- **In Kalka, watch for:** Escape, C or any tool leaves comment mode; no stray pin.

### Resolve

Resolve a thread and find it again.

- **In Figma:** Resolve, then show resolved in the panel.
- **In Kalka, watch for:** Same.
