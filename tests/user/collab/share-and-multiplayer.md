# Sharing and working together

**Story:** as a designer and a teammate, I want to share a file and edit it at the same time, so that we can work together live.

**Start:** two browsers, two people.

## Missions

### Share

Share a view link and an edit link.

- **In Figma:** Share button, permissions per link.
- **In Kalka, watch for:** Sharing is clear about who can edit.

### Together

Both edit the same artboard.

- **In Figma:** Live cursors and selections with names; follow by clicking an avatar.
- **In Kalka, watch for:** Cursors and edits appear live; no lost edits.
