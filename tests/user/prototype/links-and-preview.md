# Links and preview

**Story:** as a designer showing a flow, I want to link screens and click through them, so that a client can try the flow.

**Start:** `/?test`, two screens.

## Missions

### Link

Make a button go to the second screen.

- **In Figma:** Prototype tab, drag the blue handle to the frame.
- **In Kalka, watch for:** Something equivalent.

### Preview

Play the flow and click the button.

- **In Figma:** Present (Cmd+Alt+Enter) or the preview window.
- **In Kalka, watch for:** Preview opens and the link works.

### Back

Add a back link.

- **In Figma:** Action: Back.
- **In Kalka, watch for:** Same.
