# Copy and paste

**Story:** as a Figma user, I want copy and paste to put things where I expect, so that I can reuse parts fast.

**Start:** `/?test`, two artboards.

## Missions

### Between artboards

Copy a group from one artboard and paste it into the other.

- **In Figma:** Paste lands in the selected frame at the same position; Cmd/Ctrl+Shift+V pastes over the selection.
- **In Kalka, watch for:** Same.

### Duplicate

Duplicate a layer with Cmd/Ctrl+D and with Alt-drag.

- **In Figma:** Both duplicate; repeated Cmd/Ctrl+D keeps the offset.
- **In Kalka, watch for:** Same.

### From outside

Paste an image, an SVG from another app, and a block copied from a website.

- **In Figma:** Images and SVG paste as layers; web content pastes as text.
- **In Kalka, watch for:** Each arrives as an editable layer; a web block keeps its look.
