# Saving and reopening

**Story:** as a designer, I want my work saved and found again exactly as I left it, so that I never lose or misplace anything.

**Start:** the desktop app, or `/` in a browser that can save files.

## Missions

### Save

Make a small page and save it.

- **In Figma:** Figma saves to the cloud continuously.
- **In Kalka, watch for:** Where and in which format it goes is clear; the tab shows the name.

### Close with changes

Change something, close the tab, then the window.

- **In Figma:** No dialog: everything is saved.
- **In Kalka, watch for:** Save, Don't save and Cancel are all clearly buttons; Escape cancels.

### Reopen

Reopen it from the dashboard and from the file.

- **In Figma:** The file opens where you left it.
- **In Kalka, watch for:** Every layer is where it was on every artboard; nothing moved to another side.
