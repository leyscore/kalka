# Importing from the web

**Story:** as a designer redesigning a live site, I want to bring a page of a website into Kalka as layers, so that I start from what exists.

**Start:** `/?test`, the Kalka Snapshot extension in Chrome, a public website.

## Missions

### Grab a section

Copy a section of the website with Snapshot and paste it.

- **In Figma:** Figma needs a plugin (html.to.design).
- **In Kalka, watch for:** It looks the same as on the site, at the same size; fonts and images come along.

### Edit it

Change a heading and a button color in the pasted section.

- **In Figma:** Plugin output is editable layers.
- **In Kalka, watch for:** Text is text, buttons are frames, layout is auto layout where the site was flex.
