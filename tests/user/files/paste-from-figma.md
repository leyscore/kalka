# Pasting from Figma

**Story:** as a designer using both tools, I want to copy layers from Figma and paste them into Kalka, so that I can bring parts over.

**Start:** Figma and Kalka open side by side.

## Missions

### Copy a frame

Copy a frame in Figma and paste it in Kalka.

- **In Figma:** Figma copies its own clipboard format.
- **In Kalka, watch for:** The frame arrives editable, with auto layout, text and images.

### Copy a component

Copy an instance with variants.

- **In Figma:** Figma itself.
- **In Kalka, watch for:** What arrives, and whether it stays a component.
