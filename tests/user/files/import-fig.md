# Importing a Figma file

**Story:** as a team moving from Figma, I want to open my .fig files in Kalka, so that I can switch without redrawing.

**Start:** a .fig file exported from Figma (File > Save local copy).

## Missions

### Open

Open the .fig in Kalka.

- **In Figma:** The reference is the same file in Figma, side by side.
- **In Kalka, watch for:** All pages and frames are there.

### Compare

Compare three screens with Figma at 100 %.

- **In Figma:** Figma itself.
- **In Kalka, watch for:** Fonts, spacing, images, effects, components match; list each difference with a screenshot pair.

### Edit

Edit an imported component and an auto layout frame.

- **In Figma:** Figma itself.
- **In Kalka, watch for:** They behave as they did in Figma.
