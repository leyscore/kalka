# Exporting HTML

**Player:** a designer handing a page to a developer. **Start:** `/?test`, a page with a title, buttons and text in Inter and one other font, with a phone breakpoint.

## Missions

### Export the page

Export the desktop artboard as one HTML file with its images inside it.

Watch for: where HTML export is; the file name; one file, not a zip, when asked for one.

### Open it everywhere

Open the file in Chrome, Firefox and Safari, on a machine without the page's fonts installed if you can.

Watch for: the same fonts as on the canvas; nothing in the page that was not in the design (stray shapes, outlines, duplicated text); the tab shows a title.

### Narrow window

Make the browser window as narrow as a phone.

Watch for: whether the phone breakpoint applies; what sticks out or is cut off.

### Hand it over

Read the HTML as a developer would.

Watch for: class names that say what things are; buttons and links as real elements; no editor data left in it.
