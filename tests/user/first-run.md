# First run

**Player:** someone who has used Figma for years and opens Kalka for the first time. **Start:** a fresh browser profile at `/` (not `/?test`), or the desktop app with a new profile.

## Missions

### Get to an empty canvas

Start from the welcome screen and reach a new, empty document.

Watch for: every screen says what to do next; nothing asks for an account or a key before you can draw; skipping the setup is obvious.

### Make a desktop page

Create an artboard the size of a desktop screen and name it "Home".

Watch for: Figma users press F and pick a preset from the right panel; the presets are where they look; the name edits by double-clicking it in the layers panel or on the canvas.

### Find your way back

Go to the dashboard, then come back to the document.

Watch for: the document is still there, unchanged, with nothing asking to be saved when nothing changed.
