# Saving and reopening

**Player:** anyone. **Start:** the desktop app, or `/` in a browser that can save files.

## Missions

### Save a new document

Make a small page and save it to a folder of your choice.

Watch for: where it goes and in which format is clear; the tab shows the name; nothing is marked unsaved afterwards.

### Close with changes

Change something, then close the tab, then the window.

Watch for: the dialog offers Save, Don't save and Cancel, and each is clearly a button; Escape cancels; Don't save closes without saving.

### Reopen what you made

Reopen the saved document from the dashboard and from the file itself.

Watch for: every layer is exactly where it was, on every artboard, including the tablet and phone; nothing has moved to another side or another artboard; the view returns to where you were.
