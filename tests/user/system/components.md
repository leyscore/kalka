# Components

**Story:** as a UI designer, I want to turn a button into a reusable component, so that changing it once updates every copy.

**Start:** `/?test`, a button.

## Missions

### Make a component

Turn the button into a component.

- **In Figma:** Cmd/Ctrl+Alt+K.
- **In Kalka, watch for:** Same shortcut; the icon in the layers panel changes.

### Use it

Place three instances from the assets panel.

- **In Figma:** Assets tab, drag in; or Alt-drag an instance.
- **In Kalka, watch for:** Same.

### Update all

Change the main button color and check the instances.

- **In Figma:** All instances follow, except overridden properties.
- **In Kalka, watch for:** Same.

### Detach

Detach one instance.

- **In Figma:** Cmd/Ctrl+Alt+B.
- **In Kalka, watch for:** Same.
