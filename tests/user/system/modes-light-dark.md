# Light and dark modes

**Story:** as a product designer, I want to show a design in light and dark from the same layers, so that I do not draw it twice.

**Start:** `/?test`, a screen bound to color variables.

## Missions

### Add a mode

Add a Dark mode to the color collection with dark values.

- **In Figma:** Collection > + mode.
- **In Kalka, watch for:** Modes exist in the variables table.

### Switch a frame

Show one copy of the screen in Dark.

- **In Figma:** Frame > Appearance > the mode switch.
- **In Kalka, watch for:** The frame changes and its children follow.
