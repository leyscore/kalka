# Colors and variables

**Story:** as a design-system designer, I want named colors and spacing values, so that a change in one place updates the whole design.

**Start:** `/?test`, a page with buttons and cards.

## Missions

### Color variables

Create "brand/primary" and "surface" color variables and apply them.

- **In Figma:** Local variables, + Color; bind from the fill picker.
- **In Kalka, watch for:** The same steps; bound fills show the variable name.

### Number variables

Create a "space/md" = 16 variable and bind it to a gap.

- **In Figma:** Number variables bind to gap, padding, radius.
- **In Kalka, watch for:** Same bindings.

### Change once

Change brand/primary and watch every button.

- **In Figma:** Everything bound updates.
- **In Kalka, watch for:** Same.
