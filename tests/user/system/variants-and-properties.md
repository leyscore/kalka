# Variants and properties

**Story:** as a design-system designer, I want one button with sizes, states and an optional icon, so that the team picks options instead of copies.

**Start:** `/?test`, a button component.

## Missions

### Variants

Add Small and Large sizes and a Hover state.

- **In Figma:** Add variant; properties Size and State.
- **In Kalka, watch for:** Variants with named properties.

### Boolean and text properties

Add "Has icon" and "Label" properties.

- **In Figma:** Component properties: Boolean, Text, Instance swap.
- **In Kalka, watch for:** Same property kinds.

### Use them

- **In Figma:** Pick values in the right panel.
