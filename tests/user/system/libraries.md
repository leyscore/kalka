# Libraries

**Story:** as a team designer, I want to share components and styles across files, so that every file uses the same design system.

**Start:** `/?test`, a file with components and a second file.

## Missions

### Publish

Publish the components and styles.

- **In Figma:** Assets > Library > Publish.
- **In Kalka, watch for:** A publish flow exists.

### Use in another file

Enable the library in the second file and use a button.

- **In Figma:** Assets > Libraries > enable.
- **In Kalka, watch for:** Same.

### Update

Change the button in the library and accept the update in the second file.

- **In Figma:** A banner offers to review and accept updates.
- **In Kalka, watch for:** Updates are offered, not forced.
