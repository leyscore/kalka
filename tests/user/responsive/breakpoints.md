# Breakpoints

**Story:** as a web designer, I want tablet and phone versions of a page that follow the desktop one, so that I change a layout once and only adjust what differs.

**Start:** `/?test`, a 1440 artboard with a title and two buttons.

## Missions

### Add tablet and phone

Add a tablet and a phone version.

- **In Figma:** No equivalent in Figma: copies by hand, or variables and modes.
- **In Kalka, watch for:** The option is easy to find; the copies appear beside the desktop.

### Change only the phone

Make the title smaller on the phone, then change its text on desktop.

- **In Figma:** No equivalent.
- **In Kalka, watch for:** The phone keeps its size and takes the new text.

### Remove one

Delete the tablet, then undo.

- **In Figma:** No equivalent.
- **In Kalka, watch for:** Only the tablet goes; undo brings it back.

### Add on the phone

Add a badge on the phone only.

- **In Figma:** No equivalent.
- **In Kalka, watch for:** Whether it appears everywhere, and whether that is clear beforehand.
