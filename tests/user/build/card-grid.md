# A grid of cards

**Story:** as a product designer, I want a grid of six product cards from one component, so that I can fill a catalogue fast.

**Start:** `/?test`, a card component.

## Missions

### Grid

Place six cards in three columns with 24 gaps.

- **In Figma:** Auto layout wrap or grid.
- **In Kalka, watch for:** A wrap or grid option.

### Vary the content

Give each card a different image and title.

- **In Figma:** Override the instances.
- **In Kalka, watch for:** Overrides stay when the main card changes.

### Reflow

Make the container narrower and watch the grid go to two columns.

- **In Figma:** Wrap reflows.
- **In Kalka, watch for:** Same.
