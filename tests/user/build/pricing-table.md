# A pricing table

**Story:** as a SaaS designer, I want three plans side by side with the middle one highlighted, so that I can show pricing clearly.

**Start:** `/?test`, a 1440 artboard.

## Missions

### Build it

Three equal-height plan cards with lists of features.

- **In Figma:** Auto layout row, cards Fill, items Hug; equal height with Fill on height.
- **In Kalka, watch for:** Equal heights without typing numbers.

### Highlight

Make the middle card stand out with a border and a badge.

- **In Figma:** Stroke, absolute badge.
- **In Kalka, watch for:** Same.

### Edit a list

Add two features to one plan.

- **In Figma:** Cards stay aligned.
- **In Kalka, watch for:** Same.
