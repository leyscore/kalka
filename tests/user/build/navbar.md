# A navigation bar

**Story:** as a web designer, I want a nav with logo, links and a button that stays laid out at any width, so that the header is ready for every page.

**Start:** `/?test`, a 1440 artboard.

## Missions

### Build it

Logo left, five links centered, button right.

- **In Figma:** Auto layout row, space between, or three groups.
- **In Kalka, watch for:** Space between exists and works.

### Narrower

Resize the nav to 1024 wide.

- **In Figma:** Fill container keeps the layout.
- **In Kalka, watch for:** Same.

### Mobile version

Make a 390 version with a menu icon instead of links.

- **In Figma:** A variant or a separate frame.
- **In Kalka, watch for:** A phone breakpoint, and how clear it is.
