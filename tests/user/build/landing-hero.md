# A landing page hero

**Story:** as a web designer, I want to build a hero section: nav, headline, text, two buttons and an image, so that I can present a landing page idea.

**Start:** `/?test`, an empty 1440 artboard; no step-by-step, build it as you usually would.

## Missions

### Build it

Make the hero with auto layout, centered, max text width 640.

- **In Figma:** Frames with auto layout, text styles, Fill container for the row.
- **In Kalka, watch for:** Count the clicks and the moments of hesitation; compare with how long it takes in Figma.

### Change the copy

Make the headline twice as long.

- **In Figma:** Everything below moves down.
- **In Kalka, watch for:** Same; no overlap.

### Hand it on

Export it as HTML and open it.

- **In Figma:** Figma needs Dev Mode or a plugin for code.
- **In Kalka, watch for:** The page looks like the canvas.
