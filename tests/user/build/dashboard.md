# A dashboard

**Story:** as a product designer, I want a dashboard with sidebar, header, stat cards and a table, so that I can design data-heavy screens.

**Start:** `/?test`, a 1440 artboard.

## Missions

### Layout

Sidebar fixed 240, the rest fills; header, four stat cards, a table.

- **In Figma:** Nested auto layout with Fixed and Fill.
- **In Kalka, watch for:** Same.

### Table

A table of 10 rows and 5 columns with aligned columns.

- **In Figma:** Row components, or the newer table tools.
- **In Kalka, watch for:** Columns stay aligned when a cell grows.

### Chart

Add a simple bar chart.

- **In Figma:** Rectangles or a plugin.
- **In Kalka, watch for:** What Kalka offers.
