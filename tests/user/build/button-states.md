# Button states

**Story:** as a UI designer, I want hover and pressed states for a button, so that developers know how it behaves.

**Start:** `/?test`, a button component.

## Missions

### States

Make Default, Hover, Pressed, Disabled.

- **In Figma:** Variants.
- **In Kalka, watch for:** Same.

### Interactive

Make hover show Hover in preview.

- **In Figma:** Prototype: While hovering > Change to.
- **In Kalka, watch for:** Preview reacts to the pointer.

### Hand off

Check what a developer sees for the states.

- **In Figma:** Dev Mode shows each variant.
- **In Kalka, watch for:** Exported code includes the states.
