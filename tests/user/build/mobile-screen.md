# A mobile app screen

**Story:** as a mobile designer, I want an iPhone screen with status bar, header, list and tab bar, so that I can design apps, not only websites.

**Start:** `/?test`, an iPhone preset.

## Missions

### Build it

Header, scrollable list of ten items, tab bar at the bottom.

- **In Figma:** Auto layout; tab bar fixed at the bottom; overflow scroll in prototype.
- **In Kalka, watch for:** Something keeps the tab bar at the bottom.

### Safe areas

Keep content off the notch and the home bar.

- **In Figma:** Layout grids or padding by hand.
- **In Kalka, watch for:** Same or better.

### Scroll

Preview and scroll the list.

- **In Figma:** Prototype > overflow scrolling.
- **In Kalka, watch for:** Preview scrolls.
