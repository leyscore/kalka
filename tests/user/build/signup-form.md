# A sign-up form

**Story:** as a product designer, I want a form with labels, inputs, errors and a button, so that I can design flows with real states.

**Start:** `/?test`, a 480 frame.

## Missions

### Build it

Email and password fields with labels, and a button.

- **In Figma:** Components for inputs, auto layout column.
- **In Kalka, watch for:** Fast to build; Kalka may offer real form elements.

### Error state

Show the email field in an error state with a message.

- **In Figma:** An input variant State=Error.
- **In Kalka, watch for:** Same with variants.

### Try it

Type into the fields in preview.

- **In Figma:** Prototype only fakes it.
- **In Kalka, watch for:** If Kalka has preview, the field accepts typing.
