# Kalka Fresh credits

Kalka Fresh is the component library built into Kalka. Every component is a port to HTML and CSS of a component, shader or demo published under a permissive licence; none is copied markup. The licence and notice files of each source are in `licenses/`. Live backgrounds run Paper Shaders, which Kalka already bundles; the other Paper entries are still CSS stand-ins for a shader of the same name.
